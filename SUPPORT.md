# Support

Thanks for using Agent Factory! Here are the best ways to get help.

## Documentation
Start with the project docs:
- [README](README.md)
- [Quick Start](QUICKSTART.md)
- [Troubleshooting Guide](TROUBLESHOOTING.md)

## Questions and Discussions
If you have a question about usage or best practices, open a GitHub Discussion
(or an issue if discussions are not enabled).

## Bug Reports
If you believe you found a bug, open a GitHub issue and include:
- A clear description of the problem.
- Steps to reproduce.
- Expected vs. actual behavior.
- Logs or screenshots when helpful.

## Security Issues
Please report vulnerabilities privately via [SECURITY.md](SECURITY.md).
